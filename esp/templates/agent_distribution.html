Mission Distribution

One weighted roll over the agent's division (RollMissionType), then a random enabled template of that type at the agent's level. Weights are relative, not percentages — Roll is each type's share of its division's total. Effective is what pilots get: a rolled type with no usable template at that level falls back to kill, and if kill is empty too the agent answers “no missions available”. Template allowedFactions filtering is not modelled and can only narrow coverage further.

Mission cap

Per pilot per agent, counted on accepted missions in a rolling window — declines do not count, and the agent info window shows “Available Again” while the cap is hit. The refusal line is authorable per division on Dialogue (shell.cooldown). 0 disables the cap. Storyline agents are exempt (the invite is their gate).

Free declines

Per pilot per agent: the first decline in the window is free; another decline with the same agent inside it costs the template’s standing loss. 0 makes every decline cost standing. The agent’s lines are authorable on Dialogue (shell.decline.free, shell.decline.penalty).

Storyline deck

Storyline agents run the same offer pipeline, on an exclusive deck: they draw only templates flagged storyline on the mission template page, nobody else draws those, and they have nothing at all for a pilot who has not been invited. An invite is earned by completing consecutive missions for agents of one faction — switching faction restarts the count — at which point a storyline agent of that faction mails the pilot and waits for them. The run is only spent when an agent is actually found, so a faction with no storyline agent holds the count rather than wasting it. These agents are excluded from the division coverage above, because they no longer answer an ordinary mission request.
