Anchoring security ceiling

Normally each type carries its own ceiling in the shipped data: control towers anchor below {{printf "%.2f" .DefaultMaxSec}}, and a Moon Harvesting Array carries anchoringSecurityLevelMax 0.4 (0.3 for II and III) — which is why moon mining is a lowsec-and-below activity without a line of code saying so. Setting a value here overrides every ceiling at once, for a test shard that wants moon mining in highsec. Leave empty to use the shipped attributes.

POS templates

A template is captured from a POS players built in game: the tower type, every anchored structure's type and offset from the tower (inside its anchor radius), what each one handles, and the Production wiring. Save one from a tower above (or /possave <towerID> <name>), then stamp it at any moon here or with /posspawn <name> <moonID> [online] [fuelDays]. Placement rules (security ceiling, one tower per moon, sovereignty) apply to a stamp exactly as to /posplant.
