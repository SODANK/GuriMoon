NPC Spawner Rules

How many ships a belt wave holds, by security. What spawns is entirely the region's business — see Region Spawns. These rules only set the size of the wave.

Each belt rolls a squad tier, adds that tier's size deltas to the min–max window below, then fills every slot by weighted-random pick from that region's normal and hauler listings eligible at the system's security. A min of 0 means some belts come up empty. Commanders and officers are not in that draw — each has its own chance and its own pool, set per tier.

Wave timer (minutes)
How long a belt stays empty after its last rat dies (or after it rolled an empty wave) before it rolls a new one. Applies live — belts already waiting are judged against the new value from when they were cleared. Default {{printf "%g" .WaveTimerDefaultMin}} min. Same setting as Reseed cooldown on Region Spawns.

Squad Tiers

How hard a belt is. Every wave draws one of these, weighted, from the tiers covering the system's security — so two belts in the same system can be very different places.

Weight is relative within a band; the % beside it is that row's real share. Size Δ is added to the spawner rule's window above. Cmdr % and Officer % are the chance per wave — a commander replaces a slot the wave already had, an officer is an extra ball on top.

Sec floor is the difficulty lever. A region's listings carry a max security that already sorts them by hull — frigates 1.0, destroyers 0.8, cruisers 0.6, battleships 0.4 — so filtering the base pool at a floor instead of the system's own security leaves only the smaller hulls. Floor 0.9 in null-sec is a belt of high-sec-grade frigates. Leave it at 0 for "whatever this system's security allows". It only ever narrows, and it applies to the base pool alone: the commander and officer pools always filter at the system's real security, so a floor can never drag a null-sec officer into low-sec.

⚠ Tiers and the rarity settings are read once at boot. An edit here does not affect a running server until it is restarted.
