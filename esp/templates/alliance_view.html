Applications ({{len .Applications}})

A corporation applies from its own corp window and a Director of the executor corporation answers. Accepting joins nobody. The client tells the applicant that acceptance takes 24 hours, so the corporation joins on the sweep once the waiting period is up — only then does the application read Effective. Accept and Reject are the only answers the client's dialog offers, so they are the only two the server takes.
