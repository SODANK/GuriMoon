Create alliance

The ID is the logo. The client draws an alliance logo from a hardcoded table of 70 allianceIDs (uix.GetAllianceLogo); any other ID falls back to tile 01_01, and nothing the server sends changes that. Picking a slot below creates the alliance at that ID, which is the only way to give it a logo the game itself draws. It can be changed later on the alliance's own page — that renumbers the alliance and everything pointing at it, so picking here is the cheaper choice. A logo image uploaded on the alliance page is used by this panel, the in-game browser and killmail pages — not by the game client's own UI.
